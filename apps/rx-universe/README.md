# SAMSUNG RX Intelligence Universe

설계서 v2.2를 바탕으로 개선한 **v2.5 공개 리서치 웹서비스**입니다. 공개 주소는 [https://uhchoi2132.github.io/rx-universe/](https://uhchoi2132.github.io/rx-universe/)입니다. 커스텀 GitHub Actions 워크플로는 테스트·빌드·브라우저 검증을 통과한 산출물을 게시하고 비인증 접근 및 공개 데이터 일치를 확인합니다. 코드의 현재 변경과 실제 배포 완료 여부는 해당 워크플로 실행 결과로 구분합니다.

## 화면과 기능

8개 화면을 제공합니다.

- **Command Center**: 선택 시점의 자료·관계 현황, 최근 7일 신규 공개자료, 검토 후보, 우선 질문
- **3D Universe**: 기업·기술·사업 객체와 개별 주장·출처 레이어, 관계 방향, 1·2단계 이웃, 두 노드 연결 경로, 검색 맥락, 관계·귀속 필터, 같은 그래프의 3D/2D 탐색
- **Time Machine**: 당시까지 공개된 자료의 현재 재구성과 현재 자료를 활용한 과거 사건 재평가
- **Evidence Vault**: 문서·다중 주장·날짜·확인 상태·출처 계보·판단 한계 및 JSON·SQLite 다운로드
- **Hypothesis War Room**: 경쟁 가설의 지지·반박·맥락 자료, 대안 설명, 다음 확인 지표와 개인 검토 기록
- **Factory Twin**: 제조 실행 흐름과 책임 경계를 살펴보는 설명 화면. 실제 MES·RCS·로봇 관제 연결은 없습니다.
- **Briefing Studio**: 실제 게시일 범위로 집계하는 일간·주간·월간 브리핑, 직전 동일 길이 기간 비교, 원문 연결, JSON·인쇄/PDF
- **Action Items**: 개선 작업·선행 조건·인수 기준과 후속 기반 과제, 실행 항목 JSON

모바일과 WebGL 미지원 환경에서는 같은 자료를 탐색하는 2D 그래프를 제공합니다. 키보드 탐색, reduced-motion, 모바일 메뉴와 모달 포커스 관리도 포함합니다.

## 데이터와 그래프

`src/research-data.json`은 **2025-10-30~2026-10-30 공개자료를 조사한 81개 문서·84개 출처 귀속 주장**의 수동 스냅샷입니다. 문서마다 원문 URL, 게시일·사건일·관측일, 짧은 발췌, 원출처 그룹, 사업화 단계, 판단 한계를 저장합니다. URL 중복을 합칠 때도 서로 다른 추출 주장을 보존합니다. 수동 열람 보고, 보관 원문 확인, 검색 결과만 확인, 접근 제한을 구분하며 보고된 열람을 주장 내용의 독립 검증으로 승격하지 않습니다.

실제 화면의 그래프는 출처·주장에 연결된 모델을 사용합니다. **2026-10-30 기준 301개 노드·691개 관계**이며 날짜와 필터에 따라 달라집니다. `src/knowledge.ts`는 관계의 `source_ids`·`claim_ids`와 근거 설명을 연결합니다. 출처에 귀속된 관계와 분석가가 가설에 연결한 관계를 구분하며, 계획 발표를 출시·유료 운영 완료로 표시하지 않습니다. 삼성전자·삼성SDS·미라콤은 별도 주체이고 로봇 하드웨어 계약을 SDS RX 소프트웨어 매출로 합산하지 않습니다.

`research/*.json`에 분야별 조사와 검색 기록을 보존합니다. `python3 scripts/merge-research.py`는 통합 목록을 재생성하며 `python3 scripts/build-db.py`는 외래키·변경 방지 트리거가 있는 다운로드용 SQLite 스냅샷을 만듭니다. 공개 파일은 `/rx-universe/data/rx-research.sqlite`와 `/rx-universe/data/rx-research.json`입니다. 이는 서버에서 운영되는 데이터베이스가 아닙니다.

원문 바이트를 보관하지 않았으므로 **원문 해시는 null로 유지**합니다. `record_sha256`은 정규화한 조사 레코드의 해시이며 원문 파일의 해시가 아닙니다.

## 상세 그래프 확장: v2.5

기존 29개 노드·27개 관계에서 **기업·기술·사업 객체 147개, 주장 78개, 출처 76개**로 확장했습니다. 연결 691개는 **검토된 사업 관계 52개**, 주장·문서에 등장하는 명칭과 키워드, 원문 연결, 출처군 계보 및 가설 검토를 포함합니다. 관계 649개는 출처 귀속, 42개는 분석 매핑입니다. 이 숫자를 계약·독립 증거·기술 의존성 개수로 해석하지 않습니다.

전체 조사 목록 81건과 그래프 출처 76건의 차이는 조사기간 밖 배경 2건과 접근 차단 3건입니다. 과거 조회에는 공개일이 확인된 당시 자료만 들어가고, 현재 관측에서는 날짜 미상 14건의 열람 보고도 별도 날짜 상태로 탐색합니다. 원문 보관본의 미확보 상태는 그대로 유지합니다.

Object Explorer, 레이어·관계 유형·연결 분류, 검색과 한 단계 주변 맥락, 중심 노드의 1·2단계 이웃, 두 노드 사이의 연결 경로를 제공합니다. 방향 화살표는 원래 관계 방향이며 경로 탐색은 인과관계·실행 의존성을 주장하지 않습니다. 확대·이동·화면 맞춤과 2D 폴백, 상세 근거, 화면과 동일한 JSON 내보내기를 지원합니다. [그래프 구성·탐색·한계](docs/graph-exploration.md)를 참고하세요.

`codex/rx-universe-*` 브랜치에서는 동일한 빌드와 브라우저 검증을 실행하되 공개 배포는 건너뜁니다. `main`만 공개 배포 권한을 사용합니다.

## 리뷰 반영: v2.4

검토 대상 `89cf315` 이후 수정 사항과 이번 반영을 [항목별 대응표](docs/review-response.json)에 기록했습니다. 전체 문서·주장을 유지하면서 출처군은 **73개에서 63개로 재산정**했습니다. 같은 회사 발표·행사 발화의 반복을 독립 증거로 세지 않으며 문서 원작, 행사, 개별 발화를 따로 보존합니다. 같은 게시일과 엔터티만으로 무조건 병합하지 않고, 공유 발표의 근거 또는 분리 예외가 없는 후보쌍은 빌드에서 거부합니다. [계보 규칙·전체 검토 대장](docs/source-lineage.md)을 참고하세요.

동일 URL의 게시일·사건일 충돌은 null과 날짜의 차이를 포함해 거부합니다. 명시적인 해결 근거가 있으면 입력별 값·채택값·사유를 JSON과 SQLite에 남깁니다.

원문 보관본을 재현할 수 없는 기존 자료 **78건은 `manual_report`**, 접근 차단은 **3건**입니다. 보관 수동 열람 보고는 **0건**입니다. `primary_read`는 실제 보관 원문 URL과 본문 SHA-256을 갖춘 기록에만 허용하며, 검증되지 않은 아카이브 주소를 생성하지 않습니다. 수동 열람 보고와 검색 색인 기반 게시일은 서로 다른 확인 축입니다. 원문 보관본 확보는 미완료이며 [감사 정책](docs/source-audit.md)에 남겼습니다.

미사용 seed 모델 `data.ts`를 제거했습니다. `research.ts`의 자료와 `knowledge.ts`의 엔터티·관계가 각각 단일 원천이며 `graphView`의 공통 필터를 렌더러·내보내기에 적용합니다. 신호·엔터티·관계·출처 선택은 타입으로 분리하며, 검토 후보 전용 상세가 실제 주장·원문·한계·다음 확인을 보여줍니다.

Three.js 0.180.0은 WebGL1을 지원하지 않습니다([공식 문서](https://threejs.org/docs/pages/WebGLRenderer.html)). WebGL2 확인과 동일 자료를 사용하는 2D 폴백을 유지합니다.

## 시간 재현과 브리핑

As-known-at은 선택일까지 게시된 자료를 사용합니다. 이미 발표된 미래 계획은 공개 시점부터 표시하되 예정 상태를 유지합니다. Retrospective는 현재 조사 범위에서 과거 사건을 설명하는 후속 공개자료를 사용할 수 있습니다. 사건일 원본은 보존하며 미확인 값을 새 사실로 채우지 않습니다. 기본 Retrospective는 사건일 미상 자료의 게시일을 조회용 대체 기준으로 사용하므로 실제 사건 발생을 입증하지 않습니다. Time Machine의 별도 사건 기준일 필터는 엄격하게 사건일·예정일이 확인된 자료만 포함하고 공개 기준일과 독립적으로 작동합니다.

이는 **현재 수집한 자료로 당시 공개정보를 재구성**하는 기능입니다. 당시 실제로 수집·판단했던 상태를 보존한 운영 로그는 아닙니다. 게시일 미확인 자료는 현재 관측 시점에서 별도 표시하며 과거 공개정보 집합과 기간별 신규 집계에 넣지 않습니다. 조사기간 밖 배경 자료도 최근 1년 자료와 구분합니다.

브리핑 기간은 양끝 날짜를 포함합니다.

| 선택 기준일 2026-10-30 | 게시일 범위 | 현재 목록의 신규 문서 |
| --- | --- | ---: |
| 일간 | 2026-10-30 | 0건 |
| 주간 | 2026-10-24~2026-10-30 | 4건 |
| 월간 | 2026-10-01~2026-10-30 | 9건 |

신규 0건도 정상 결과입니다. 신규 공개 문서와 누적 문서를 구분하고 직전 동일 길이 기간의 문서 수를 비교합니다. 출처 그룹 수는 독립 사건 수가 아니며 사업화 단계별 문서 수도 고객·매출·가동 실적이 아닙니다. 문서 내용의 정정·철회와 수집 실행별 증감은 추적하지 않습니다. 신호 후보에는 출처·검토 이유·한계·다음 확인 지표가 연결되며 검증된 고영향 신호로 자동 확정되지 않습니다.

## 개인 검토와 운영 한계

War Room의 검토 사유와 판정 변경은 **현재 브라우저의 localStorage**에만 기록됩니다. 날짜·모드별 기록을 구분하며 원문·주장의 사실 상태를 바꾸지 않습니다. 공동 검토, 서버 권한 검증 또는 변조 방지 감사 로그가 아니며 브라우저 저장소 삭제 시 사라질 수 있습니다.

자동 수집, AI 주장 추출·추론, 서버 API·운영 DB, OIDC·역할 권한, 공동 검토, 현장 데이터 연결과 08:00 자동 게시가 미연결입니다. 마지막 자동 성공 업데이트 `last_successful_update`는 null입니다. UI 배포와 데이터 자동 갱신은 별개입니다. 전수 조사 완료·공식자료 누락률·중복 정밀도·실제 운영 KPI는 측정하지 않았으며 조사 공백을 화면과 데이터 메타데이터에 기록합니다.

## CI 권한과 재현성

168개 패키지의 정확한 버전·무결성을 `package-lock.json`에 저장하고 `npm ci`로 설치합니다. workflow 기본 권한은 비어 있고, build에는 `contents: read`만 부여합니다. `pages: write`, `id-token: write`는 deploy 작업에만 있습니다. checkout은 자격 증명을 저장하지 않습니다. 공개 `release.json`의 커밋 ID, JSON, SQLite를 해당 배포 커밋과 비교합니다.

별도의 브랜치 기반 `pages build and deployment` 실행도 관측되어 커스텀 게시와 경쟁할 수 있습니다. 저장소의 Settings → Pages → Source를 **GitHub Actions**로 전환해야 배포 경로가 하나가 됩니다. 현재 연결 도구에는 Pages 관리 설정 변경 기능이 없고, 공식 설정 변경 API는 Administration 쓰기 권한도 요구하므로 CI 토큰의 권한을 확대하지 않았습니다. AI-016으로 남겨두었으며 각 배포에서는 커스텀 작업의 마지막 완료와 공개 산출물 커밋 일치를 확인합니다.

## 개발 및 검증

React·TypeScript·Vite 기반 정적 웹서비스입니다. Node.js 22 이상과 Python 3을 사용합니다.

```bash
npm ci
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:browser
npm run dev
```

로컬 주소: `http://localhost:5173/rx-universe/`

- `src/research.test.ts`: 공개·사건·예정 날짜, 다중 주장 보존, 출처 계보, SQLite 무결성·재생성 검사
- `src/knowledge.test.ts`: 관계별 실제 주장 연결, 과거 시점 누출 방지, 날짜 미상 현재 표시, 계획·계약 구분과 가설 근거 매핑
- `src/reviews.test.ts`: 검토 사유·판정 제한, 변경 이력, 저장 복원, 날짜·모드 분리와 손상된 기록 거부
- `src/briefing.test.ts`: 실제 기간 0/4/9건, 동일 길이 비교, 출처 그룹, 다중 주장, 미래정보 배제와 하드웨어 계약 경계
- `scripts/browser-check.mjs`: 생산 빌드의 데스크톱·모바일·그래프·시점·검토·브리핑·내보내기 검증과 스크린샷
- `.github/workflows/rx-universe.yml`: 테스트 → 타입 검사·빌드 → Chromium 검증 → 공개 배포 → 비인증 접근 및 JSON·SQLite 일치·무결성 확인

GitHub Pages 저장소에서는 소스가 `apps/rx-universe/`, 공개 산출물이 `/rx-universe/`에 위치합니다. 서비스 데이터는 공개자료와 명시된 분석가 가설을 사용합니다. Next.js·FastAPI·PostgreSQL 기반 운영 서비스와 원문 수집·승인·감사 체계는 후속 구현 범위입니다.
