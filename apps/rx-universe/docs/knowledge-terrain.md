# 지식 지형과 두 시점 비교 · v2.7

## 참고 자료의 확인 범위

- [Qoyra 제작자 설명](https://www.reddit.com/r/SideProject/comments/1xgrxgp/i_know_i_saved_it_somewhere_i_just_cant_find_it/)에서 주제·프로젝트 구역, 상세도와 탐색 단계, 공간적 기억에 대한 설계 의도를 확인했다.
- [Qoyra 공유 페이지](https://www.qoyra.app/?share=1f9c5acd47f449dcbca5ea922e9d8907)는 이번 웹 도구에서 열리지 않았다. 실제 WebGL 조작·반응성·성능을 검증한 것으로 보고하지 않는다.
- 약 500개 노트 사용 사례와 노트 체인 접기는 사용자가 전달한 제작자 설명이다. 이번 조회에서 모든 댓글을 재확인하지 못했으며 성능 근거로 사용하지 않았다. 인용 후기의 5,000개 노트는 RX 데이터나 RX 벤치마크가 아니다.
- 시간 비교는 RX를 위한 설계 추가다. 직접 확인한 Qoyra 기능으로 귀속하지 않는다.

## 기존 기능과 이번 변경

v2.5에 이미 있던 공개일·사건일 분리, 출처 기반 그래프, 2D 대체 탐색, 관계 상세, 1·2단계 이웃, 경로 탐색, 좌표 정책을 유지한다. v2.6 진행분의 공식 출처 조사·확장 DB·Source Survey도 같은 앱에 보존한다.

이번 변경은 다섯 주제 구역의 요약에서 시작하는 탐색, 현재 구역과 전체 보기 안내, 공통 검색을 사용하는 객체·주장·원문 목록, 실제 두 날짜의 공개·관측·노출 차이를 비교하는 화면이다. 새 사이트·외부 계정·유료 서비스·권한 변경은 없다.

## 단일 그래프의 지형 투영

`terrainRegions()`는 `graphView()`가 반환한 현재 가시 그래프만 요약한다. 지도 구역은 별도 사실 노드가 아니며 기존 `KnowledgeCluster`와 고정 중심점을 사용한다. 세 개의 같은 크기 등고선은 탐색 단계를 안내한다. 높이·면적·자료량을 기업의 역량·영향력·신뢰도 점수로 사용하지 않는다.

문서 수는 현재 보이는 Source 노드, 주장 수는 Claim 노드, 출처군 수는 Source의 `origin_key`를 각각 중복 제거해 계산한다. 출처군은 독립적으로 검증된 근거 수가 아니다. 구역을 가로지르는 관계와 같은 출처군은 여러 구역에 걸칠 수 있어 구역별 숫자를 독립 증거처럼 합산하지 않는다.

주제 구역·객체 유형·레이어 제한을 먼저 적용한 뒤 검색 맥락·이웃·경로 탐색을 계산한다. 구역 제한을 벗어난 연결을 자동으로 복원하지 않는다. 전체 관계 지도로 돌아가면 전체 범위에서 탐색할 수 있다. 지도·목록·JSON 내보내기는 같은 가시 노드·관계 집합을 사용한다.

각 객체의 모델 좌표와 구역 중심은 날짜·필터에 따라 재배열하지 않는다. 날짜·필터 변경만으로 카메라를 다시 맞추지 않는다. 구역으로 새로 진입하거나 사용자가 확대·화면 맞춤을 선택할 때 보기 범위를 바꾼다. 이는 좌표 재배치가 아니다. 현재 고정 인벤토리의 좌표 정책은 데이터 모델 자체가 대규모로 바뀔 때의 영구 공간 주소까지 보장하지 않는다.

## 날짜 비교의 의미

`compareSnapshots()`는 동일 모드와 사건 필터, 검색·주제·레이어·관계 조건을 두 날짜에 적용한다. 아래 항목은 서로 다른 집계다.

- **기간 중 공개 문서**: `(이전 날짜, 이후 날짜]`의 게시일. 이미 발표된 미래 계획을 포함한다.
- **게시일 미상 관측 자료**: 같은 기간의 `accessed_at`. 공개일·사건일·출시일로 취급하지 않는다.
- **새로 보이는 노드·연결·주장**: 두 가시 그래프 ID 집합의 차이. 실제 사업 관계의 신규 성립·종료를 의미하지 않는다.

Retrospective에서는 현재 지식으로 이전 시점을 재평가하므로 구간 중 발표된 문서가 이전 화면에도 포함될 수 있다. 공개 문서 증가와 그래프 노출 증가가 반드시 같지 않다.

주장 버전·정정·철회·반박 판정의 운영 이력이 없으므로 해당 비교는 `supported:false`, 각 이력 값은 null로 반환한다. 분석가가 가설에 연결한 `contradicts` 관계를 주장의 반증 완료로 계산하지 않는다. 이는 현재 카탈로그의 재구성이며 당시 실제 저장된 그래프 버전의 재생이 아니다.

## 접근성과 검증

요약 지형은 WebGL을 요구하지 않는 SVG와 HTML 버튼으로 제공한다. 모바일에서는 동일 구역·집계·이동 기능을 목록으로 제공한다. 세부 그래프의 기존 2D·키보드 노드/관계 목록·원문 연결을 보존한다. 드래그 없이 구역 선택·검색·상세·확대·화면 맞춤을 조작할 수 있고 reduced-motion을 존중한다.

단위 테스트는 가시 ID 집합, 구역 집계, 좌표 불변, 미래 정보 배제, 날짜 미상 정책, 실제 공개일·관측일 비교, 미지원 이력의 null 상태를 검사한다. Playwright는 지도·목록·내보내기 일치, 구역 선택의 키보드 조작, 두 날짜의 실제 차이, 모바일과 WebGL 실패 후 근거 접근을 검사한다.

성능 보고는 CI에서 실제 실행한 그래프의 노드·관계 수와 환경, 관측한 화면 전환 시간만 사용한다. 수천 개 노트나 미측정 규모의 성능을 보장하지 않는다.
