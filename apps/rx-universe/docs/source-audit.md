# 원문 열람과 재현 가능한 감사의 구분

기준일: 2026-10-30 · 사용자 리뷰 m2 대응

## 현재 상태

전체 조사 문서 81건 중 78건은 `manual_report`, 3건은 `access_blocked`입니다. 실제 원문 보관본과 그 바이트의 해시를 함께 확보한 문서는 0건입니다. 따라서 81건 모두 재현 가능한 원문 감사 요건이 충족되지 않았으며, 보관본 미확보를 해결한 것으로 표시하지 않습니다.

기존 `primary_read` 78건은 조사 당시 본문을 열람했다는 수동 보고였습니다. 외부 검토자가 같은 보관본을 다시 열어 확인할 수 있는 증빙은 확보하지 못했으므로, 이번에 `manual_report`(수동 열람 보고 · 아카이브 미확보)로 등급을 변경했습니다. 3건의 접근 차단 상태는 그대로 유지합니다. 이번 조치는 증거 상태를 바로잡는 부분 완화이며 원문 캡처·아카이브 확보의 완료가 아닙니다.

## 상태 정책

| 상태 | 의미 | 허용하지 않는 해석 |
| --- | --- | --- |
| `manual_report` | 조사자가 본문을 읽었다고 기록했지만 재현 가능한 보관 증빙이 없는 상태 | 독립 감사 완료, 내용의 사실 확정 |
| `access_blocked` | 원문 접근에 실패하거나 차단된 상태 | 원문 직접 확인 |
| `primary_read` | 실제 확인 가능한 `archive_url`과 원문 바이트의 `content_sha256`을 갖추어야 하는 등급 | URL·해시 문자열을 채우기만 하면 내용까지 검증되었다는 뜻 |

`primary_read`에는 아카이브 URL과 SHA-256 메타데이터를 요구하는 lint가 적용됩니다. **메타데이터 형식 검사 통과는 원격 아카이브의 존재·접근 가능성·내용 일치 검증과 다릅니다.** 실제 승격 전에는 보관 URL을 열고, 그 보관 객체의 정확한 바이트로 해시를 다시 계산하며, 해당 주장과 근거 위치가 그 객체에 존재하는지 확인해야 합니다. 원문 URL을 아카이브 URL로 복사하거나, 확인하지 않은 Wayback 시각을 조합하거나, 조사 레코드 JSON의 해시를 원문 해시로 대신 사용해서는 안 됩니다.

아카이브의 캡처 시각과 우리 시스템의 관측 시각도 구분해야 합니다. 뒤늦게 만든 보관본은 당시 공개일이나 당시 시스템 관측 이력을 소급 증명하지 않습니다. 원문이 정정되면 기존 보관본을 덮어쓰지 않고 새 버전과 변경 관계를 기록해야 합니다.

## 열람 상태와 게시일 근거는 별도 축

`verification`은 열람·감사 증빙 상태이고, `date_basis`는 게시일을 어디에서 확인했는지 나타냅니다. 본문을 읽었어도 본문에 게시일이 없으면 `date_basis: search_index`일 수 있습니다. 두 필드는 논리적으로 모순되지 않지만 각 한계를 함께 표시해야 합니다.

`se-006`(Samsung Research DAM-VLA)은 본문 열람 보고가 있고 게시일 2026-03-11은 검색 색인에 근거합니다. 따라서 현재 상태는 `manual_report`와 `search_index`의 조합입니다. 본문 열람 보고가 검색 색인 날짜의 정확성까지 보증하지 않으며, 검색 색인 날짜가 본문을 읽지 않았다는 뜻도 아닙니다. 원문에 표시된 날짜 또는 검증 가능한 추가 날짜 근거 확보는 여전히 필요합니다.

## 이번 아카이브 확인 시도와 한계

삼성SDS 발표, 삼성전자 뉴스룸, 한국거래소 KIND 반기보고서, 삼성전자 IR PDF의 대표 URL 4건에 대해 기존 Wayback 보관본 조회를 시도했습니다. 웹 도구의 availability API 접근은 실패했고 해당 URL의 보관본 검색에서도 확인 가능한 결과를 얻지 못했습니다. 로컬 직접 접근 역시 프록시 연결 실패로 원문 바이트나 해시를 확보하지 못했습니다. 이 결과는 보관본이 세상에 존재하지 않는다는 증명이 아니라 이번 환경에서 확인하지 못했다는 뜻입니다. 검증되지 않은 아카이브 URL이나 해시는 추가하지 않았습니다.

## 그래프와 공개 제공 범위

상태 변경 뒤에도 기존 공개자료의 URL, 짧은 발췌, 출처 귀속 주장과 분석가의 연결은 보존합니다. 그래프의 관계는 출처가 발표한 내용 또는 분석가의 해석으로 표시하며, 원문 감사 완료나 독립 검증된 사실로 승격하지 않습니다. 개인 검토 기록 역시 원문 보관 증빙이나 공인된 검증을 대신하지 않습니다.

후속 작업은 이용 조건에 맞는 실제 보관본 확보, 바이트 해시 계산, 근거 위치 대조, 캡처·관측 시각 기록입니다. 기사 전문을 공개 서비스에 재게시하지 않으며, 공개 화면은 필요한 짧은 인용·메타데이터·원문 링크 중심으로 유지합니다. 권리와 이용 조건을 확인할 수 없는 자료는 전문 공개 저장을 진행하지 않습니다.
