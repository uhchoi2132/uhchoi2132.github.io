# RX Universe 그래프 탐색 · v2.5

## 자료에서 그래프까지

그래프는 기존 공개자료 목록을 더 세밀하게 투영한 것입니다. 이번 확장은 새로운 원문을 확보하거나 원문 보관본을 재현 검증했다는 뜻이 아닙니다. `research-data.json`의 자료와 추출 주장, 검토된 명칭 사전, 주장에 직접 연결한 사업 관계를 이용합니다. 원문 접근 차단·검색만 확인한 자료는 사업 사실의 근거가 되지 않습니다.

기업·조직·제품·기술·프로젝트·현장·계약과, 개별 주장·원문 자료를 각각 노드로 제공합니다. 삼성전자, 삼성SDS, 미라콤, 제조 관계사는 구분된 객체입니다. 노드에는 유형, 별칭, 출처 ID와 주장 ID를 보존합니다. 같은 문서의 반복 인용은 기존 출처군으로 관리하며 노드 개수나 연결 개수를 독립 검증 수로 해석하지 않습니다.

## 연결의 의미

- 사업 관계는 주장 문장에 담긴 개발·협력·투자·제품 구성·활용 등의 방향을 표현합니다. 계획은 계획 상태를 유지합니다.
- 문서·주장·키워드 연결은 무엇이 어디에서 언급되었는지 찾아가는 탐색 관계입니다. 언급만으로 소유·투자·계약·실행 의존성을 만들지 않습니다.
- 가설 및 분석 매핑은 점선으로 구분하고 판단 근거와 한계를 표시합니다.
- 모든 연결은 구체적인 주장과 원문으로 되돌아갈 수 있습니다. 선을 선택하면 해당 연결만의 설명·날짜·한계·자료를 표시합니다.

MES, Job, Task, Scheduling, RCS가 함께 등장해도 공식 인터페이스가 없는 한 임의의 `depends_on` 사슬을 사실로 만들지 않습니다. 실제 실행 순서와 기술 책임의 공백은 그대로 남깁니다.

## 탐색 방법

1. 전체 레이어에서 기업·기술·주장·원문의 구조를 확인합니다. Object Explorer는 표시 중인 사업·기술 노드를 연결 수와 함께 제공합니다.
2. 기업·기술 레이어 또는 주장·원문 레이어로 범위를 좁힙니다. 관계 유형과 출처 귀속/분석 연결 필터를 함께 적용할 수 있습니다.
3. 검색의 ‘주변 연결 포함’을 켜면 검색 결과의 한 단계 이웃을 함께 표시합니다. 꺼져 있으면 직접 일치하는 노드만 표시합니다.
4. 중심 노드와 1단계/2단계 깊이로 주변 관계를 펼칩니다. 노드 상세의 주변 탐색 버튼 또는 그래프 더블클릭으로 중심을 바꿉니다.
5. 두 노드를 골라 최소 연결 경로를 찾습니다. 탐색은 양방향으로 이동할 수 있지만 화살표는 실제 등록된 관계 방향을 유지합니다. 이 경로는 인과관계·업무 실행 순서·기술 의존성의 증명이 아닙니다.
6. 3D에서는 회전·이동·확대와 화면 맞춤을 사용합니다. 2D와 키보드 목록에서도 같은 노드·관계와 상세 근거를 제공합니다.

## 표시·시간·내보내기 규칙

좌표는 군집을 읽기 위한 배치이며 물리적 위치나 조직 계층을 의미하지 않습니다. 노드 크기는 유형 구분이고 사업 중요도나 성공 확률이 아닙니다. 전체 보기에서 짧은 이름을 우선 표시하고, 작은 주장·출처 노드의 전체 제목은 상세와 목록에서 확인합니다. 라벨을 축약해도 실제 노드와 연결을 삭제하지 않습니다.

공개일 기준과 별도의 사건일 제한은 모든 레이어에 적용됩니다. 이미 공개된 미래 계획은 공개일부터 포함하며, 날짜 미상 자료는 현재 관측 화면에서만 표시합니다. 시간 이동이나 필터로 제외한 자료를 검색·경로 탐색이 다시 끌어오지 않습니다.

렌더러와 내보내기는 같은 `graphView` 투영을 사용합니다. JSON의 `view.exploration`에는 레이어·관계 유형·출처 분류·중심 노드·깊이·경로·검색 주변 포함 설정이 기록됩니다. `graph.nodes`와 `graph.relations`는 화면의 실제 집합입니다.

## 검증과 한계

단위 테스트는 실제 주장·출처 연결, 시점 제한, 잘못된 별칭 매칭, 관계 방향, 필터 이후의 이웃·경로 탐색을 확인합니다. 브라우저 테스트는 3D/2D, 검색, 레이어, 관계 상세, 주장·원문, 주변 탐색, 경로 및 내보내기 일치를 확인합니다. 별도 검증 브랜치의 빌드를 확인한 뒤 공개 브랜치에 반영합니다.

공개자료의 일부를 분석한 수동 스냅샷입니다. 자동 수집, 공유 서버 검토, 현장 실시간 관제, 공식 제품 의존성 명세의 공백은 이번 시각화 확장으로 해결되지 않습니다.
